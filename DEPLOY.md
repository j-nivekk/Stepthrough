# Running Stepthrough on a server

The server deployment and administration guides live on the
**[Stepthrough Wiki](https://github.com/j-nivekk/Stepthrough/wiki)** and under [`docs/wiki/`](docs/wiki/) in this
repository:

- [Server deployment (Docker)](docs/wiki/Server-Deployment-Docker.md) ([Wiki](https://github.com/j-nivekk/Stepthrough/wiki/Server-Deployment-Docker)) — requirements, Docker Compose install, settings, nginx/HTTPS, upgrades, backups, OCR and building the image
- [Server deployment (without Docker)](docs/wiki/Server-Deployment-Without-Docker.md) ([Wiki](https://github.com/j-nivekk/Stepthrough/wiki/Server-Deployment-Without-Docker)) — running from a Git checkout with `systemd`, offline OCR models, upgrades and differences vs. Docker
- [Managing accounts](docs/wiki/Managing-Accounts.md) ([Wiki](https://github.com/j-nivekk/Stepthrough/wiki/Managing-Accounts)) — admin panel, CSV bulk user import, password links, shared/visitor limits, server settings, progress, usage and traffic reports

To run Stepthrough on your own computer instead, see
[Installing and starting Stepthrough](docs/wiki/Installing-and-Starting.md)
([Wiki](https://github.com/j-nivekk/Stepthrough/wiki/Installing-and-Starting)).
